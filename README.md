# 樽見OTO鉄道 SNS フレーム

SNS に投稿する画像と動画を組むエディター。背景に樽見の写真や動画を敷き、画像・動画の枠とテキストを重ねて、PNG / JPEG / MP4 に書き出す。

```sh
npm install
npm run dev        # → http://localhost:3210
```

## 使い方

- 縦横比: 1:1 (1080×1080)、3:4 (1080×1440。Instagram の通常投稿)、4:5 (1080×1350)、4:3 (1440×1080)、16:9 (1920×1080)、9:16 (1080×1920)
- 横に並べる: 上のバーの「枚数」でアートボードを横に 1 〜 10 枚並べる。背景は全体に広がり、枠やテキストは境目をまたいで置ける (1 枚の絵を分けて投稿するとき)。書き出しとプレビューは 1 枚ずつ (ファイル名の末尾に -1, -2 …)
- 書体: Helvetica + ヒラギノ角ゴ、Helvetica + ヒラギノ明朝 (どちらも英数字は Helvetica)、樽見 OTO ストローク
- モーション: 樽見 OTO ストロークのテキストは、右の欄の「モーション」で線が書かれていく動きを付けられる (開始の秒、書き終えるまでの秒数、1 文字ずつ / ずらして / 同時に)。下のバーで再生して確かめ、MP4 で書き出す。止めて頭に戻しているあいだは書き終えた状態を見せる。フォントに無い文字は線で書けないので、順番が来たらそのまま出る
- 色面: 帯や札に使う長方形 (R)。色と、内側に付く縁 (色・太さ) を決められる。「塗らない」にすると縁だけになる
- 札: テキストの右の欄の「札」で、文章の後ろに地の色と縁のある長方形を敷ける。大きさは文章 + 余白 (左右・上下) + 縁で、文章の量に合わせて変わる。左右はテキストの幅 (W) の中央に来る。「上下に伸びる」にすると、Y が上下の中央になり、文章が増えても中央のまま上下に広がる
- テンプレート: 「ファイル → 新規」に並ぶ。`bottom-band` (下に緑の帯と白のロゴタイプ)、`frame-logo` (全体に緑の縁、右下に緑のロゴタイプを写真の上へ直接。縁は押しても選ばれないようロックしてある)、`center-card` (中央に緑の縁の白い札とテキスト。Web の札と同じ見え方。札は文章の量に合わせて大きさが変わる)、`performer` (出演者の紹介。上に緑のストロークフォントの名前 (中央、動きつき)、その下に窓 (丸) の形の写真の枠、写真の右下に重なる緑の縁の札 (ストロークフォント、動きつき)。札は文章が増えると下へ伸びる)。どちらも背景に写真や動画を落とせる。作ってから縦横比を変えても、帯は下、札は中央に付いたまま
- テンプレートの差し替え: アートボードごとに、その上のドロップダウンで選ぶ (「テンプレートなし」で外す)。背景・縦横比・枚数、自分で足したレイヤー、ほかのアートボードのテンプレートはそのまま。テンプレートの場所に書いた文章と枠に入れた素材は、新しいテンプレートの同じ種類の場所へ移る。移す先が無いものは隠したレイヤーとして取っておき、場所のあるテンプレートに戻したときに入る。アートボードを減らすと、そのアートボードのテンプレートのレイヤーも消える
- 縦横比を変えたとき: 枠・色面・テキストは形と大きさを保つ。左右も上下も、中央にあるものは中央のまま、ほかは近いほうの端からの距離を保つ (左右はそのレイヤーのあるアートボードの中で)。幅 (高さ) いっぱいのものは、いっぱいのまま
- 素材: 左の「素材」に樽見の写真 (`public/presets/` の縮小版。`../docs/photo/selected/<区分>/*.JPG` から `node scripts/presets.mjs` で作る) が並ぶ。画像・動画のファイルは紙面か「アップロード」に落とす
- 入れ方: 素材を紙面に落とすと背景に、枠に落とすとその枠に入る (画像の枠には画像、動画の枠には動画)。素材を押すと、選んでいる枠 (無ければ背景) に入る
- 枠の形: 右の欄の「形」で、四角 / 窓 (丸) / 窓 (角) を選ぶ。窓は Web の写真の枠 (KV の窓) と同じ 2 種類で、角の丸みは幅に対する比 (丸 15.5%、角 5.7%)。線は付かない (切り抜くだけ)。背景には無い
- 2 値化: 素材の入った枠と背景は、右の欄の「2 値化」を「かける」にすると 2 色になる。advertising の組み合わせ (web の開催の背景の写真) と同じ式で、輝度が閾値より明るければ明るい側の色、暗ければ暗い側の色。既定も同じ (閾値 0.77、暗い側 #c7faff、明るい側 #ffffff)。動画にも掛かる
- 編集: 枠はダブルクリックで素材の位置と拡大を調整 (はみ出た分も薄く見える。ドラッグで位置、角かホイールで拡大)、テキストはダブルクリックで入力。Cmd + Z で取り消し、Cmd + D で複製、[ ] で重ね順、矢印で 1px (Shift で 10px)。テキストの入力中は、カーソルのある文字間だけを Option + ← / → で 0.01 ずつ詰める / 空ける (Shift で 0.05。文字の大きさに対する割合。全体の字間とは別に足される)。入力中に文字を選んで Cmd + Shift + > / < で、選んだ文字だけを大きく / 小さく (全体の大きさに対する倍率を 0.05 ずつ。0.2 〜 5 倍。行の高さは変わらず、ベースラインをそろえる)
- 紙面: スペース + ドラッグで動かす、ピンチか Cmd + ホイールで拡大、右上の % で画面に合わせる
- `?p=<id>` を付けて開くと、そのプロジェクトを開く (最後に開いたものとしては覚えない)
- プレビュー: Instagram のフィード・グリッド・リール、X での見え方 (切られる範囲の注意つき)
- 書き出し: PNG / JPEG は今の見た目を 1 枚に。MP4 は 30fps の H.264 + AAC (ブラウザの中で作る。Chrome で動かす)

## 置き場所

| 場所 | 中身 |
| --- | --- |
| `data/projects/<id>.json` | プロジェクト (自動保存)。手元で動かすときだけ |
| `data/assets/` | 落とした画像・動画 (git には入れない)。手元で動かすときだけ |
| `public/logos/name-line-white.svg`、`name-line-green.svg` | ロゴタイプの白と緑 (`../advertising/media/print/logos/name-line.svg` に白の塗りと大きさを足した写し) |
| `public/presets/` | 樽見の写真の縮小版 (thumb 360px / view 2400px) と一覧 (index.json)。`node scripts/presets.mjs` で作る (ImageMagick が要る。写真を足したら走らせ直す)。デプロイに含める |
| `templates/*.json` | レイアウトのテンプレート。プロジェクトと同じ形の JSON (中身の無い枠がプレースホルダー) を置くと「ファイル → 新規」に並ぶ |

## 作り

- `lib/stroke/` 樽見 OTO ストロークの線の動き。`animation.ts` `geometry.ts` `types.ts` は `../font/src/core` からの写し、線のデータ `public/fonts/TarumiOTOStroke-Regular.stroke.json` と OTF は `../web/public/fonts` からの写し (フォントを書き出し直したら写し直す)
- `lib/doc.ts` ドキュメントの形、`lib/render.ts` canvas への描画 (編集画面と書き出しで共通)、`lib/export.ts` 書き出し (動画は mediabunny)
- `components/Editor.tsx` 全体、`Stage.tsx` 紙面、`LeftPanel.tsx` 素材とレイヤー、`Inspector.tsx` 設定、`Preview.tsx` 投稿の見え方

## 保存先 (手元と Vercel)

`lib/storage.ts`。どちらになるかは `next.config.ts` が決める (Vercel でビルドすると `browser`)。

- 手元 (`npm run dev`): プロジェクトは `data/projects/`、落とした素材は `data/assets/` (サーバーのファイル)
- Vercel: サーバーにファイルを書けないので、開いているブラウザの中 (IndexedDB) に保存する。プロジェクトも落とした素材も端末・ブラウザごとに別々で、ほかの人や別の端末とは共有されない。ブラウザのサイトデータを消すと消える
- 手元でも URL に `?store=browser` を付けると、ブラウザの中に保存する (Vercel と同じ動きの確認用)
- 樽見の写真とテンプレートは、どちらでもリポジトリのファイル (`public/presets/`、`templates/`) から出す
